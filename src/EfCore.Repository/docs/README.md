# EfCore.RepositoryPack

A general-purpose library providing a generic repository pattern implementation for Entity Framework Core, supporting all SQL-based databases.  
Supports .NET 6, .NET 7, and .NET 8.

---

## Features

- Generic repository pattern for EF Core  
- Works with all SQL-based databases (SQL Server, PostgreSQL, MySQL, etc.)  
- Clean, maintainable, and testable data access layer  
- Asynchronous CRUD operations  
- Transactional support  
- Extensible and easy to integrate  

---

## Installation

Install via [NuGet](https://www.nuget.org/packages/EfCore.RepositoryPack):

```bash
dotnet add package EfCore.RepositoryPack
```

> #### Note:  
> To use **[EfCore.BaseRepositoryPack](https://www.nuget.org/packages/EfCore.BaseRepositoryPack)**, you also need to install the base package
